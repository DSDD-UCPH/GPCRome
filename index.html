    Input format

    Each line: a receptor, then optionally a value and style properties.

    ADRB2gene, UniProt accession or entry name, HGNC/ChEMBL ID, synonym
    ADRB2 7.5with a value (also ADRB2,7.5 or tab separated)
    ADRB* GPR1??wildcards
    allevery receptor
    class:B1a class: A, B1, B2, C, F, T2, rogues, orphan
    family:adenosinea GPCRdb receptor family
    ligand:peptidea GPCRdb ligand type
    fill=red size=8also shape= stroke= opacity= label=yes text=
    red star labelbare colours, shapes and label work too
    set labels=allchange a global setting (see CSV export for all keys)

    Later lines override earlier ones, e.g. all fill=#ccc followed by ADRB* fill=red.
